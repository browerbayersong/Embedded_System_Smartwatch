### 3.2 遇到的问题与解决措施

| 问题现象 | 原因分析 | 解决措施 | 状态 |
| :-- | :-- | :-- | :-- |
| I2C 初始化 OLED 无响应 | I2C 时钟配置不正确 + 上拉电阻缺失 | 开启 I2C1 时钟并外接 4.7kΩ 上拉电阻 | ✅ 已解决 |
| MPU6050 数据抖动明显 | 未进行低通滤波与零偏校准 | 启动时采集 200 组数据求均值做零偏，滑动均值滤波 | ✅ 已解决 |
| 旋转编码器误触发 | 未做软件消抖 | EXTI 回调中加入 20ms 消抖 + 边沿状态机判断 | ✅ 已解决 |
| **一键开关电路关断失败** | **MCU 关机控制引脚未正确拉低保持电路自锁 / 或 MOS 管导通逻辑反** | **排查 MCU 关机引脚电平序列，必要时更换 NMOS/PMOS 方案或增加软件延时释放** | **🔄 调试中** |
